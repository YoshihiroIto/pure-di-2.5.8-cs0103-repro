# Pure.DI 2.5.8 `overriddenBoolean` / CS0103 reproduction

This standalone .NET 10 project depends only on Pure.DI. With the default Pure.DI version (2.5.8), the generated `Composition.g.cs` references `overriddenBoolean` outside its scope and the build reports CS0103.

## Reproduce

Run these commands from this directory:

```powershell
dotnet build Repro.csproj -p:PureDIVersion=2.5.8
dotnet build Repro.csproj -p:PureDIVersion=2.5.6
```

Both builds fail with exit code 1. In the observed builds:

- **2.5.8:** CS0103 for `overriddenBoolean` in `Composition.g.cs(117,35)`.
- **2.5.6:** DIE000 for an unbound `bool` in `Composition.cs(19,33)` because `FileSystem` is also a direct root.

This is **not** a reproduction of a project that builds with 2.5.6 and fails with 2.5.8. It demonstrates the CS0103 generated by 2.5.8, but does not establish the cause of the Filedini upgrade failure.

The small dependency graph combines a `Func<bool, FileSystem>` factory, a `Lazy<Dialogs>` dependency, singleton bindings, and multiple roots. Generated code is available under `obj/generated` after a build.
